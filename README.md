# 🏆 EY AI Hackathon

> 团队成员：John · Melody · Ruby · Dana · April

## 项目简介

本项目参加 EY AI Hackathon 比赛。每位成员在各自分支上独立开发，最终择优合并。

## 分支说明

| 分支 | 成员 | 说明 |
|------|------|------|
| `main` | — | 主分支，最终合并成果 |
| `John` | John | 个人开发分支 |
| `Melody` | Melody | 个人开发分支 |
| `Ruby` | Ruby | 个人开发分支 |
| `Dana` | Dana | 个人开发分支 |
| `April` | April | 个人开发分支 |

## 协作流程

1. 每人从 `main` 切到自己的分支开发
2. 完成功能后提交并推送
3. 代码评审后合并到 `main`
