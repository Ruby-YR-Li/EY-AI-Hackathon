# Demo 展示话术模板

## 1. 开场

我们选择的业务场景是：待填写。

原流程的主要痛点是：人工处理耗时、容易遗漏、结果不够结构化。

## 2. 解决方案

我们的 POC 做了一个从输入到输出的完整闭环：

1. 上传业务文件或输入业务信息。
2. 系统自动读取并提取关键字段。
3. AI 或规则引擎进行比对、判断和归类。
4. 输出结构化结果、风险提示或差异报告。
5. 用户可以下载结果，并进行人工复核。

## 3. 现场演示

- 第一步：展示输入材料。
- 第二步：上传或加载样例。
- 第三步：点击分析按钮。
- 第四步：展示结果表、摘要和异常项。
- 第五步：导出报告或说明下一步处理。

## 4. 业务价值

这个方案的价值主要有三点：

1. 把重复性人工核对转为自动化处理。
2. 把非结构化材料转成可复核的数据结果。
3. 保留人工判断入口，适合审计和企业业务场景。

## 5. 后续扩展

如果继续完善，可以接入更多文件格式、业务规则库、权限控制和历史结果追踪。
