# 费用底稿 Review 助手资料理解记录

## 目标

本记录用于沉淀销售费用、管理费用底稿 Review 助手的资料理解、规则来源和工具设计，方便团队成员在 2 小时现场赛中快速接续。

| 目录 | 用途 |
| --- | --- |
| `资料库/标准底稿/` | 标准底稿模板，用于识别标准 sheet、字段、填列方式和应有程序。 |

## 资料关系

1. `U_exp SWP VC&VD 20251231 .xlsx` 是主审计底稿。
2. `TOD SWP U_Exp 20251231 .xlsx` 是详细测试底稿。
3. 科目余额表和序时账是底层账务资料。

5. Excel 版 SOP 提供标准底稿结构、检查点和标准填列样例。
6. Markdown 版 SOP 提供更细的解释、原因和易错点。

## 已识别的可自动 Review 点

### 1. Lead 基础信息检查

检查对象：`Uexp.00 Lead`

可检查内容：

- 客户名称是否填写。
- 期末和分析日期是否填写。
- TE/SAD 是否填写。
- 适用会计准则是否填写为准则，而不是货币。
- 记账本位币是否填写为货币，而不是准则。

已发现示例：

- `Uexp.00 Lead!C7` 为 `CNY`，疑似将适用会计准则填成货币。
- `Uexp.00 Lead!C8` 为 `IFRS`，疑似将记账本位币填成准则。

### 2. 汇总页 PSP 执行状态检查

检查对象：`汇总`

可检查内容：

- 每一项程序是否填写“执行”状态。
- 若选择“不执行”，是否填写具体原因。
- 拒绝执行理由是否过于笼统。
- 汇总页选择与实际底稿内容是否一致。

### 3. 法律、诉讼、咨询、中介类费用检查

检查对象：`VD.00 管理费用BKD`、序时账、`VD.01.3 复核法律费用`

可检查内容：

- 筛选科目名称或摘要包含 `法律`、`律师`、`诉讼`、`咨询`、`中介` 的费用。
- 若存在此类费用，但汇总页声明不执行法律费用复核，应提示不一致。
- 检查是否已在 `VD.01.3 复核法律费用` 中记录复核。

已发现示例：

- `VD.00 管理费用BKD` 中存在 `管理费用_咨询费`、`管理费用_法律服务费`、`管理费用_诉讼费`、`管理费用_中介服务费`。
- 汇总页中 `VD.01.03复核法律费用` 被标记为不执行，理由为“本期无复核法律费用”，与底稿线索可能不一致。

### 4. BKD 异常波动和 Notes 检查

检查对象：`VC.00 销售费用BKD`、`VD.00 管理费用BKD`

可检查内容：

- P 列或 Q 列标记为需要进一步调查时，Notes 索引是否为空。
- Notes 是否有对应分析说明。
- 变动金额或变动比例超过阈值时，是否记录调查过程。
- 定性异常项目是否有 Note 和证据索引。

### 5. 截止性测试完整性检查

检查对象：`VC&VD.01.4 截止性测试`

可检查内容：

- 测试期间前后天数是否填写。
- 测试期间确定依据是否填写。
- 样本是否填写凭证编号、日期、金额、明细科目。
- 是否填写交易凭据名称、编号、交易发生日期。
- 是否标记本期或资产负债表日后期间。
- EY Works 结论是否填写。

### 6. TOD 样本总体和抽样检查

检查对象：`TOD SWP U_Exp 20251231 .xlsx`

可检查内容：

- 样本总体是否填写。
- 总样本池与剔除后样本池是否有数据。
- 样本池金额是否能与 BKD 或抽样工具输出核对。
- 是否保留 Skywind 抽样输出。
- 不同交易类别是否被错误合并为同一样本总体。

## 工具设计建议

工具名称：

`Expense Review Assistant` / `费用底稿 AI Review 助手`

### 页面结构

1. 资料上传或选择
   - 主底稿 `U_exp`
   - TOD 底稿
   - 科目余额表
   - 序时账
   - 审计程序要求
   - SOP Excel

2. 自动 Review
   - 基础信息检查
   - PSP 执行状态检查
   - 特殊费用风险检查
   - BKD Notes 检查
   - 截止性测试检查
   - TOD 样本总体检查

3. 结果展示
   - 风险总数
   - High / Medium / Low 分类
   - 涉及 sheet 数量
   - Review Notes 表格

4. 结果导出
   - CSV 或 Excel Review Notes
   - 可选 HTML 报告
   - 可选底稿标注副本

### Review Notes 字段

| 字段 | 说明 |
| --- | --- |
| `risk_level` | High / Medium / Low |
| `file` | 问题所在文件 |
| `sheet` | 问题所在 sheet |
| `location` | 单元格、行号或区域 |
| `issue_type` | 问题类别 |
| `review_note` | 给 Senior/Manager 的 Review Note |
| `suggested_action` | 建议修改或补充动作 |
| `source` | 规则来源，如 SOP、Review checklist、程序要求 |

## 最小 MVP 范围

2 小时现场赛建议只做以下功能：

1. 使用 Streamlit 做本地页面。
2. 读取现有输入资料。
3. 执行规则检查。
4. 输出 Review Notes 表格。
5. 支持下载 CSV。
6. 展示风险汇总卡片。

暂不做：

- OCR。
- 复杂 LLM Agent 工作流。
- 数据库。
- 登录权限。
- 完整标注回写 Excel。
- 多文件深度证据链解析。

## Demo 叙事

推荐展示话术：

1. Manager Review 费用底稿时，需要检查程序是否执行、底稿是否填完整、异常费用是否充分调查。
2. 传统 Review 依赖人工逐页查找，耗时且容易遗漏。
3. 本工具读取标准 SOP、程序要求和待 Review 底稿，自动生成 Review Notes。
4. 输出结果能定位到具体 sheet 和单元格，并给出建议修改动作。
5. 人工仍保留最终判断权，工具用于提高 Review 效率和一致性。
